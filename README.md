# Health-RI Metadata Model
This repo holds the **Health-RI Metadata Model**, which is used in the [National Health Data Catalogue]([https://catalogus.healthdata.nl/).

## Technical specifications
To view specifics of the metadata model per class and property, please visit the **[documentation page](https://health-ri.github.io/metadata-documentation/)**.
<br>**SHACL shapes** corresponding to the latest version of the model can be found in the [Shapes](https://github.com/Health-RI/health-ri-metadata/tree/master/Formalisation(shacl)/Core) folder in this repository.

Looking for the **Excel file** with all classes and properties? This can be found [here](https://github.com/Health-RI/health-ri-metadata/blob/master/Documents/Metadata_CoreGenericHealth_v2.xlsx).

## How to cite

This repository maintains the **Health-RI Metadata Model**, including schema workbooks, SHACL shapes, controlled vocabulary resources, and related machine-readable artifacts.

If your work uses, implements, extends, or evaluates the metadata model or its artifacts, please cite this repository using the metadata provided in [CITATION.cff](CITATION.cff). GitHub's **Cite this repository** feature can also be used to generate a citation.

The corresponding **human-readable Health-RI Metadata Model specification** is maintained separately in the [metadata-documentation repository](https://github.com/Health-RI/metadata-documentation). If your work refers to its technical explanations, definitions, property descriptions, cardinalities, or usage guidance, please cite that specification using its own `CITATION.cff`.

If your work relies on both resources, cite both. In all cases, identify the version(s) used.
