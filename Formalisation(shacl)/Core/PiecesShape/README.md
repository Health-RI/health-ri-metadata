# Health-RI Core shape files

Generated SHACL files separated by schema class, including main and supporting classes. These individual shapes already reflect the **for-FDP specification**, including its implementation adaptations.

These are the files supplied to `FAIRDataPointSchemaTool` when publishing schemas to an FDP. They also provide the pieces assembled into:

- [FairDataPointShape](../FairDataPointShape/): bundles for individual configured schemas, including their supporting shapes.
- [ValidationShape](../ValidationShape/): all individual shapes combined into one validation graph.

For the shared generation context, configuration, and reported title-cardinality limitation, see the [core overview](../README.md).
