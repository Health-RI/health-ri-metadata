# SHACL templates

Excel templates for SHACL node and property shapes, organized by schema class. The corresponding core entity shape files are in [PiecesShape](../PiecesShape/).

The 19 v2.1.0 templates are intermediate SHACL definition workbooks associated with the individual class shapes. See [Documents](../../../Documents/README.md) for the model and FDP workbook roles, and the [core overview](../README.md) for the resulting shape outputs.

The precise workbook-to-template and template-to-Turtle conversion commands require confirmation from the generation maintainers.
