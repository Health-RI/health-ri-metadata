# Dataset value lists

Tab-separated value lists for data domains (`edam:has_topic`) and measurement techniques (`schema:measurementTechnique`). Each file records term IRIs, labels, and source vocabularies.

## EDAM Bioimaging identifiers

The [measurement-technique value list](schema-measurement-technique.tsv) includes terms from [EDAM Bioimaging](https://github.com/edamontology/edam-bioimaging). Although these terms are defined in the EDAM Bioimaging ontology, their IRIs do not currently resolve to individual concept pages through the standard EDAM resolver. This is because the extension remains in a pre-release stage, with persistent, resolvable identifiers planned for its production release.

The original IRIs are retained to preserve references to the source ontology. They should be reviewed when resolvable identifiers become available. In the meantime, the concepts can be consulted through the [EDAM Bioimaging ontology](https://edamontology.org/EDAM-bioimaging.owl) or [NCBO BioPortal](https://bioportal.bioontology.org/ontologies/EDAM-BIOIMAGING).
