# Validation Shapes

[HRI-Datamodel-shapes.ttl](HRI-Datamodel-shapes.ttl) combines all individual shapes from [PiecesShape](../PiecesShape/) into one graph for RDF instance validation tools.

The combined file retains the **for-FDP specification** used by the other shape outputs. Combining the shapes does not remove FDP-specific adaptations or establish parity with the model workbook. See the [core overview](../README.md) for the packaging relationships and validation considerations.

For online RDF instance validation, see the [Health-RI RDF Validator](https://www.itb.ec.europa.eu/shacl/healthri/upload). Its deployed shape version may differ from the files in this repository.
