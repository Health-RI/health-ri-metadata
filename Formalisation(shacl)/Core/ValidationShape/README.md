# Validation Shapes

[HRI-Datamodel-shapes.ttl](HRI-Datamodel-shapes.ttl) combines all individual shapes from [PiecesShape](../PiecesShape/) into one graph for RDF instance validation tools.

The combined file retains the **for-FDP specification** used by the other shape outputs. Combining the shapes does not remove FDP-specific adaptations or establish parity with the model workbook. See the [core overview](../README.md) for the packaging relationships and reported title-cardinality limitation.

Maintainers identify this combined file as the artifact linked to the [Health-RI RDF Validator](https://www.itb.ec.europa.eu/shacl/healthri/upload). The online service's deployed shape version must be checked separately when interpreting its results.
